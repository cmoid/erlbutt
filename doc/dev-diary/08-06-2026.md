## [erlbutt](https://github.com/cmoid/erlbutt)

Spent a lot of time testing this past week, erlbutt now has 274 eunits and 71 CT tests. I think it's in good shape though I'll likely double that amounts of tests before I'll call it releaseable. It's pretty functional now, easily runs for days with no troubles. It's also about 13K lines of code, excluding all the test cases. For me that's pretty much the limit of what I can keep in my head.

EarlButt has been running as a pub/room on my old thinkpad at home, opening up a port on my router. The last few days I spent time sorting out how to install it on a VPS as a service running under a dedicated account. I went with Hetzner, I think a German outfit, that seemed reasonable and affordable. With Claude's help I wrote up the details of how to do this in [installing erlbutt](https://github.com/cmoid/erlbutt/blob/main/doc/ops/vps-install.md).

To end users EarlButt is still at pub.cmoid.org, all I needed to do was change the DNS A record to point to the new server.

Working with Claude is like reading Journey to the West. If you're familiar with that classic at the beginning of each chapter it recapitulates almost the entire story up to that point. Claude documents that way and wants to detail how every change got to be what it is, rather than just describing the actual current state. I spend a bit of time cleaning up and she still thinks 3 levels of nested case statements is ok in a functional language.

It is an incredibly productive tool, especially if you know what it is you want to build. What I like a lot is it's ability to read huge logs and suss out bugs. For example it found what I think is a issue in `ssb-ebt` where it assumes sequences it uses in persistent clocks are monotonically increasing. It makes use of `max(remembered, received)` when considering what to replicate. This breaks a common use case that allows users to migrate their `.ssb` database to a new machine using replication. When received is 0 nothing is ever sent. What's worse is when .eg. remembered is 20 and new messages come in from other peers, say 21 and 22, `ssb-ebt` will send those two. This was how I uncovered a bug in erlbutt where I wasn't checking the chain as well-formed.

## maxbutt

Still works like a champ. Using an SSH tunnel I can remsh into a running erlbutt node. Nothing beats a REPL when you really want to see what's going on. I don't know how folks get by without them.
