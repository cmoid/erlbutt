## [erlbutt](https://github.com/cmoid/erlbutt)

I'm going to bring [git-ssb](https://github.com/clehner/git-ssb) back to life, for a few reasons:

 * I need a replacement for Github. MSFT is increasingly annoying. The company is okay but I dislike the products. Some of the other forges are ok, but are now taking political stands against AI.
 * I want to test the plugin mechanism in erlbutt. `ssb-git` is going to be a plugin, with it's own repo, that one can either build into erlbutt at build time or drop in to a running node. Erlbutt follows the `ssb` `muxrpc` conventions with manifests, etc. The silkpurse and plumtree apps already do this more or less, but I need to really flesh it out.
 * I'll start with an `sbutt` like CLI and maxbutt from emacs. Ideally I should be able to use it directly with [magit](https://magit.vc).
 * [@cel](@f/6sQ6d2CMxRUhLpspgGIulDxDCwYD7DzFzPNr7u5AU=.ed25519) did such an awesome job on `git-ssb` that all the messages are still on the mainnet and there's no need to change anything. There is a clean separation of concerns. This will be compatible, and if any nodejs folks want to resurrect the node version it will have no problem talking to erlbutt.
