## [erlbutt](https://github.com/cmoid/erlbutt)

 We now have garbage collection, GC, based on a replication set that is computed from the follow graph and the hop count. There are separate sbutt commands for feeds and blobs. For both of them there is a plan phase and a run phase. A grace option allows the feeds to be quarantined for the grace period, during which time they can be restored. When purged they are removed from the disk and storage is reclaimed. Over time as we follow/unfollow and/or muck with the hop count, we can build up a huge database. My follow graph is small yet I had 43K feeds on it. The guide contains [details on GC](https://github.com/cmoid/erlbutt/blob/main/doc/guide/sbutt.md#feeds-the-graph-no-longer-reaches). *NOTE*: the node must be stopped to run GC for the feeds. The sbutt command will warn if it can't grab the LOCK. The plan can be run for blobs against a running node, safely.

I'll push another release as soon as I figure out how best to do releases with [ssb_git](https://github.com/cmoid/ssb_git) 
 
## [The Commonwealth of Scuttlebutt](%gUxXVdV04PVya17jAa19Kar70fxUVHOs7T/0qkrIFtc=.sha256)

I haven't had any feedback on archiving feeds or glimpses, both of which are good extensions for managing onboarding. The other main issue many had with the original protocol is *same-as*, but that seems to have resolved itself pretty well with clever naming.

Lately I've been thinking about private messages. Some butts have expressed opinions that they aren't quite kosher. I'm curious as to the thinking on that. I suspect it's because they impose a burden on peers. We assume that private messages we are replicating are mainly gossip and not illegal content. 

I've also been thinking about using `SSB` as a family chat app (assuming a really true end-user mobile app). This would require some real-time capabilities, .eg. a known pub that is always running, and is a centralization point. This all comes back to *trust* and governance of pubs and other community resources. I find it disgusting that we're using WhatsApp for personal family conversations.
